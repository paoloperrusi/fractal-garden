# Fractal Tree Garden 🌲✨

An interactive 3D procedural simulation of generative fractal tree growth, ambient ecosystems, and organic algorithmic botany.

🔗 **Live Demo:** [https://paoloperrusi.github.io/fractal-garden/](https://paoloperrusi.github.io/fractal-garden/)

---

## Overview

**Fractal Tree Garden** is a browser-based generative art experience that simulates the organic growth of fractal flora in a dynamic 3D garden environment. Built natively with HTML5 Canvas and JavaScript with zero external runtime dependencies.

## Key Features

- 🌱 **Procedural Growth Engine:** Watch branches continuously branch and unfurl in real-time according to mathematical recursion and stochastic parameters.
- 🎮 **First-Person & Full-View Navigation:**
  - **Walk Mode:** Gravity and jump physics to explore the garden from ground level.
  - **Fly Mode:** Free-roaming aerial camera to soar through the fractal canopy.
  - **Orbit / Full View:** Dynamic cinematic rotational showcase.
- 🎨 **Multiple Algorithms & Styles:** Diverse generative branching algorithms, tree silhouettes, foliage shaders, and coloration profiles.
- 🔬 **Single Tree Laboratory:** Inspect, parameterize, and design individual fractal trees in creative mode or random showcase mode.
- 🍃 **Environmental Simulation:** Dynamic wind forces that sway branches, atmospheric depth fog, customizable floor grids, and dynamic climate events.
- 📸 **High-Res Screenshot Export:** Capture and save high-resolution screenshots of unique procedural gardens directly to your device.

## Controls

| Key / Action | Action |
| --- | --- |
| **W, A, S, D** | Move / Walk / Fly |
| **Q / E** | Ascend / Descend (Fly mode) |
| **Space** | Jump (Walk mode) |
| **Double Space** | Toggle between Walk and Fly mode |
| **Click + Drag** | Look around / Pitch and Yaw |
| **O** | Toggle Full View / Cinematic Orbit |
| **↑ / ↓** | Increase / Decrease growth speed |
| **← / →** | Increase / Decrease concurrent trees count |
| **C** | Clear & respawn entire garden |
| **H** | Toggle HUD navigation guide |

## Getting Started

### Online
Experience the live simulation at [https://paoloperrusi.github.io/fractal-garden/](https://paoloperrusi.github.io/fractal-garden/).

### Local Setup
```bash
git clone https://github.com/paoloperrusi/fractal-garden.git
cd fractal-garden
# Open index.html directly in any web browser or serve locally:
npx serve .
```
